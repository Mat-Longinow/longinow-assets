# 🎨 Crowd7 — Square "C7" Mark (variations)

Distilled from the Crowd7 **long logo** (`logo-long-words-and-symbol.png`) per Mat's directive (2026-06-08) and the Alfred→Creative Director brief `tr_20260608_160054`.

**Construction (faithful derivative, not a redesign):** the real white geometric **'C'** glyph cropped straight from the *CROWD* wordmark, set beside the real blue-gradient **'7'** cropped from the same source — same letterform, same gradient (top-navy → bottom-cyan), same near-black background (`#0A0A0A`). No font substitution, no diffusion. This is **not** the existing fused C-hugging-7 monogram (`logo-symbol-only.png` / repo `c7.png`) — Mat specifically wanted the typographic 'C' + '7'.

Built by `agents/creative-director/projects/2026/crowd7-c7-square/build_c7.py` (re-runnable).

## The cuts

1. **`c7-square-01-primary-black.png`** — **recommended primary.** C and 7 side-by-side, tight spacing, on the near-black brand tile. The natural app-icon / Slack-tile / social-avatar form. 932×932.
2. **`c7-square-02-primary-transparent.png`** — same lockup, transparent background. For placing on any dark surface. ⚠️ The 'C' is white, so on a *light* preview background this reads as "just a 7" — that's expected; use on dark.
3. **`c7-square-03-tight-black.png`** — tighter letter-spacing, near-black. Reads best at the smallest sizes (favicon / 32px) where the 'C' and '7' need to stay distinct without wasted gap.
4. **`c7-square-04-loose-black.png`** — airier letter-spacing + padding, near-black. Calmer, more "premium" breathing room.
5. **`c7-square-05-overlap-transparent.png`** — the 'C' and '7' slightly kiss/overlap, transparent. The most distinctive / logo-y option; for dark surfaces.

Helper crops (`_glyph-C.png`, `_glyph-7.png`) are the isolated source glyphs — kept for re-composition.

## Recommended use

- **App icon / Slack workspace tile / social avatar:** `01-primary-black`.
- **Favicon (32px):** `03-tight-black` (max separation at tiny size).
- **Overlay on dark imagery / hero:** `02-primary-transparent`.
- **Wordmark-adjacent badge with extra polish:** `04-loose-black`.

SVG was not produced (would require matching the exact bespoke typeface to vector); these PNGs are pixel-faithful crops of the brand source and scale cleanly down from 932px. If a true vector favicon is needed later, that's a follow-up trace.

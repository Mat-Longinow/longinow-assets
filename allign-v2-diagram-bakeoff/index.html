Concept A1 — diagnostic

"Where are you?"

The ladder, standalone. Job: a reader locates themself in ~4 seconds. Emotional gradient bottom→top: L0 is cramped/dark/dense, L4 is open/light/airy. The tell — not just the level name — is what makes someone wince and recognize themselves.

"How do I progress?"

Studio Lead's read + the two open questions

Bake-off verdict: A1 and A2 both land — each does one job, survives mobile at a glance, and slots into its own IA section (A1 = §4 The Ladder, A2 = §5 The Stack per All-istar's proposed IA). B, even rough, confirms the predicted risk: decoding which bracket maps to which rung takes more than the two seconds a hero graphic gets. Recommend: build A1 + A2 for the live site, save the combined form for the one-pager/deck where Mat is narrating it out loud — matches All-istar's own prediction in the brief.

Open question 1 — Webflow-hybrid vs. standalone

Call: Webflow-hybrid, same pattern as Arch (~/Desktop/arch — thin Webflow loader + real page content shipped via git push, no Designer wall). Reasons: (1) v1 is already a static single-file build that slots into this pattern cleanly — no migration cost. (2) Mat's own site is lower cadence than Arch, but the hybrid pattern's real payoff is edit-and-ship without touching Designer, which matters just as much for a one-person practice site that'll get revised again once the outreach machine finds out what messaging actually converts. (3) Standalone would mean a second hosting/deploy surface to maintain for a site with no CMS need — pure overhead.

Open question 2 — v1 revision vs. fresh v2

Call: fresh v2, carrying v1's design-token system forward — agrees with All-istar's lean. The keep-list (hero line, "everything still routes through you," closing CTA, the whole token architecture) is real and worth preserving, but the IA is different enough (stat bar, pain-card grid, ladder section, stack section, process strip, FAQ accordion — none of which exist in v1) that patching v1 in place would fight the existing section order more than it would save. Build clean against the same tokens; port the surviving copy lines in, don't inherit the shell.
